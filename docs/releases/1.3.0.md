Leading now does more of what a reader does with a note: follows it into the rest of the vault, marks it up, takes passages away, and puts it on paper.

- **Embeds.** `![[picture.png]]` shows the picture and `![[Note]]` or `![[Note#Heading]]` shows that note or section in place, found anywhere in your vault, as Obsidian finds them.
- **A glance at linked notes.** Rest the pointer on a wikilink, or a link to another Markdown file, and the note's opening (or the section it names) appears beside it.
- **Coloured code.** Code blocks that name their language are coloured, in a quiet palette for each theme. Thirty-one languages, Swift and Python to SQL and YAML.
- **Tick tasks while reading.** Click a box and `- [ ]` becomes `- [x]` in the file; ⌘Z takes it back.
- **Your highlights, listed.** View › Show Highlights (⌥⌘L) lists them beside the text by section; click one to go there. Copy puts them all on the clipboard as Markdown, colours included (also Format › Copy All Highlights).
- **Copy as Quote (⇧⌘C).** The selection as a Markdown quotation, with a link back to the note and section it came from.
- **Focus (⌘D).** Everything but the paragraph you are reading recedes.
- **Page by Page.** Space and the arrow keys move exactly a screen less a line, so you never lose your place.
- **Print and Export as PDF.** The file set for paper, in your typeface, always on light paper.
- **Quick Look.** In Finder, select a Markdown file and press Space to see it as Leading sets it.

Nothing here reaches the internet. The Quick Look preview runs in a sandbox. Inside a sandbox, WebKit will not start a page without network permission, so the preview holds that permission, but it makes no connection: the page forbids every network request.
