Leading now sets math and draws diagrams.

- **Math.** LaTeX between dollars is typeset, as Obsidian writes it: `$e^{i\pi}+1=0$` within a line, and `$$…$$` (or a ```` ```math ```` block) on its own. A dollar before a price stays a dollar, so "$5 and $10" reads as written. Formulas appear with the page, in proper math fonts, in every theme.
- **Mermaid diagrams.** A ```` ```mermaid ```` block is drawn as a diagram in the page's own colours and reading font, and redrawn when you change the theme. Flowcharts, sequence diagrams, and the rest of Mermaid's types work. A diagram that cannot be drawn shows its source instead.

Both are bundled with the app, so nothing is fetched from the internet. Edit mode still shows the Markdown as written.
