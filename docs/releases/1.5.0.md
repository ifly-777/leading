Leading can now keep a note private. Encrypt one note at a time with a password; it locks itself when you step away.

- **Encrypt a note.** File › Encrypt… asks for a password twice. The note keeps its name and stays a Markdown file, so links to it and sync still work; Obsidian and other apps see only a short notice. It is encrypted with AES-256.
- **It locks when you leave.** Closing the lid, sleep, locking the screen, the screen saver or switching users locks every encrypted note. File › Lock Encrypted Notes (⌃⌘L) locks them at once. Your password opens a note again where you left off.
- **Change Password… and Remove Encryption…** are in the File menu too.

**There is no way to recover a note if you forget its password.** Copies made before you encrypted it, in Time Machine or a sync service's history, are not encrypted. Do not edit an encrypted note in another app, including an older version of Leading: any change to the encrypted block makes it unreadable.
