Leading 1.5.1 makes encrypted notes safer, and adds a guide.

- **Check your encrypted notes.** In 1.5.0, File › Encrypt… could occasionally leave a note unencrypted while seeming to succeed. This happened when another app had changed the note just before. Open each note you encrypted: it should ask for its password. If one opens without asking, encrypt it again.
- **A damaged note can be brought back.** If another app changes an encrypted note's block, even by one character, the note no longer opens. Leading now keeps a copy of each encrypted note whenever it saves or opens one. Enter the password as usual: if it opens a kept copy, Leading says the note was changed outside Leading and offers to restore that copy. The copies are encrypted, and live only on this Mac.
- **No plain copy left behind.** Locking a note within two seconds of encrypting it could leave its unencrypted text in File › Revert To. It no longer does.
- **The Leading Guide.** Help › Leading Guide (⌘?) explains everything Leading does, how to write Markdown, LaTeX math and Mermaid diagrams, and lists every keyboard shortcut. You can highlight it, but not edit it.

Encryption still cannot protect a note from someone who can change or delete the file, so keep a backup of any note that matters. There is no way to recover a note if you forget its password.
