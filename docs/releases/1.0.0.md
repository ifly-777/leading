The first public release.

- **Read** Markdown as a well-set page: Literata and four other faces, three column widths, light, sepia and dark themes, an outline of the headings, and Find that ignores case, accents and curly quotes.
- **Edit** the source with ⌘E. Changes save as you go, with every earlier version a click away.
- **Highlight** while reading, in five colours, stored the way Obsidian and Highlightr store them.
- Reads Obsidian notes: callouts, wikilinks, properties and highlights.

Leading has no account and sends nothing. It checks for updates only if you turn that on.

New to Leading? macOS will say it could not verify the app the first time you open it. The disk image has a one-page guide to the fix.
